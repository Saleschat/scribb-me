## Product docs reference text in this style
API keys don't expire. Rotate them on a schedule, and whenever someone with access leaves the team.

To rotate a key:
1. Create a new key in **Settings** > **API keys**.
2. Update every service that uses the old key.
3. Revoke the old key.

Requests with a revoked key fail with `401`. Check your logs for those errors after you revoke it.
